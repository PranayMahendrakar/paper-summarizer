# 📄 Scientific Paper Summarizer

**AI-Powered Research Paper Analysis**

Author: Pranay M

## Overview

A Llama-based system that creates concise, accurate summaries of complex scientific papers with multiple output formats.

## Features

- **Multiple Summary Types**: Lay, technical, executive, tweet thread, blog post
- **Key Findings Extraction**: Primary, secondary, unexpected findings
- **Methodology Analysis**: Study design, sample, controls, validity
- **Visual Abstract**: Graphical abstract planning
- **Paper Comparison**: Compare multiple papers
- **Citation Summary**: Ready-to-cite paragraphs
- **Implications**: Theoretical, practical, policy implications
- **Public Version**: Jargon-free explanations

## Installation

```bash
ollama pull llama3.2
pip install -r requirements.txt
```

## Usage

```bash
python main.py
```
